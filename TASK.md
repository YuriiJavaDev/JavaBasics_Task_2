### Imagine you're assembling a sentence piece by piece. Write a program that prints two lines to the screen, each on a new line. Use different System.out.println() commands for this:

#### - First line: "`I'm learning Java.`"
#### - Second line: "`This is interesting!`"

#### Print each word (`I', `I'm learning, `Java`, `This is`, `interesting`) with a separate System.out.print() or System.out.println() command.

**Requirements:**

- Each word must be printed using a separate System.out.print() or System.out.println() command.
- The words should be printed in the following order: "I", "I'm learning", "Java", then "This is", "interesting".
- The result should be two lines on the screen: the first one is "I'm learning Java.", the second one is "This is interesting!" - Each of the two summary lines should be displayed on a new line on the screen.
